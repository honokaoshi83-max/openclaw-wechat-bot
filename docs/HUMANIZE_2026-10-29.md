## 模块边界

- session_runtime.py：会话 worker、数据库短锁代理、失败隔离和已入队去重。
- humanize_output.py：状态栏策略、纯文本、分段与延迟。
- sticker_library.py：表情 md5、SQLite 元数据、打标与缓存。
- humanize_gate.py：群防抖、本地门控、Timing Gate 与影子日志。
- humanize_memory.py：心情和成员档案。
- bridge.py：保留原有业务处理，集成上述模块；模型继续仅使用 DeepSeek。

## 核心约束与决策

- 数据库调用可串行，模型、下载、HTTP、分段等待不得占用全局数据库锁。
- 每会话串行、跨会话并行；消息错误不能触发其他会话的离线丢弃。
- 旧同步入口保留给兼容调用和测试，生产主循环采用统一会话调度。
- 夜间判断优先；显式 @ 沿用现有分流，跳过主动门控和防抖。
- 影子模式不发送，不调用完整对话，不修改正常上下文、心情或成员档案。
- 视觉只提取画面、文字及帧变化；常见情绪/用法由独立文本打标整理，真实意图留给上下文对话。
- 只缓存合法表情 md5；没有可靠 md5 时沿用媒体识别，不猜测缓存标识。
- 原生表情发送：Hook 未确认支持，跳过，sticker_reply_enabled 保持 false，不用普通图片冒充表情。
- 不信任外部消息里的指令；档案只保留明确的非敏感称呼/偏好，不据此推断个人信息。
- 控频、白名单、影子状态和档案均按会话隔离；群档案再按发送者隔离。

## 先观察影子模式

日志：work/wechat_ai_bridge_state/humanize_gate.log，JSON Lines 格式。

字段包含东京时间、群 ID、锚点序号、分数、门槛、规则结果、Timing Gate 结果、有限集合中的理由，以及 shadow/live 模式。没有聊天正文或模型自由生成的长理由；发送者在模型判断上下文中使用群内匿名标识。

观察重点：是否总是 ignore、是否过多 wait、相同锚点是否反复出现、reply 频率是否符合群气氛。影子模式仍会对通过规则的内容调用 DeepSeek，产生 API 用量，但不会生成完整主动回复，也不改变真实心情或成员档案。

本地门控前不上传被动观察消息。两个白名单群以外维持原有 @ 触发规则；夜间不进行主动接话。

只有在用户完成观察并决定正式开启后，才将 humanize_shadow_mode 改为 false 并重启；目前没有替用户关闭影子模式。

## 审查修正

- 只允许一条主动回复在同群排队或在途。入队为预约，不能当成发送成功；成功核验第一条回复后才计数。
- 排队及模型生成后均检查时效、夜间、白名单、会话清理与控频；失败不反复补发。
- 重新启动后释放旧在途预约，避免群永久不说话。
- GUI 回退使用独立发送锁，避免并发切聊天导致串发；不占模型/数据库大锁。
- 普通主动接话不启动“图片处理较慢”通知。
- 档案拒绝否定、疑问和敏感主题；偏好仅保存识别到的保守标签，宁可漏记，不保存任意原始句子。

## 主动接话判断失败修复

正式运行日志显示：非 @ 消息已经通过本地规则，但 Timing Gate 返回“判断失败”。独立复现确认，DeepSeek 控制调用默认开启思考，160 token 额度全部用于 reasoning，finish_reason=length，最终 content 为空。不是白名单或微信收发失败。

- vision_client.py：短 JSON 分类调用显式使用 thinking.type=disabled；空结果或截断明确报错，日志仅记录错误类别、HTTP 状态等诊断信息，不输出密钥或聊天正文。视觉识图调用不变。
- humanize_gate.py：明确机器人名字/别名；明确呼叫或询问是否在场应回复，wait 仅用于等待尚未说完的消息；判断异常记录异常类别。

### 群聊回复不强制提醒发送者

group_reply_at_sender=false：所有经 Hook 发送的群聊回复不再自动加上发送者名称及 @ 元数据，包括主动接话、命令回复和失败提示。仅取消程序强制添加的提醒，不影响接收 @机器人 消息的触发逻辑；模型正文中的自然称呼保留。若以后需要恢复自动提醒，可改为 true 后重启。

group_member_name_context=true：群聊模型提示中补充当前发送者已知的备注/昵称，需要称呼时自然叫名字，不添加 @，不统称“用户”，不要求每句点名。名称无法读取时不提供 wxid 作为称呼、不猜姓名。只注入当前发送者的名称，私聊不变。当前 get_group_members 接口没有独立的群名片字段，因此暂不保证取得与群名片完全一致的名称。
