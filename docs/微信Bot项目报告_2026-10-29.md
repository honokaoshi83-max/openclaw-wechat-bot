## 一、项目概况

本项目将微信账号“大肥鱼”接入 OpenClaw 和 DeepSeek API，为私聊及微信群提供对话、图片理解、引用内容分析和联网搜索。

2026年10月29日完成架构精简：停用本地模型，移除千问文字与视觉接口、本地生图和改图入口。当前模型推理统一使用 DeepSeek API；微信消息读取、媒体提取、消息发送、桥接、守护及搜索服务仍在本机运行。

**当前结论：Bot 已启动，AI 微信已登录，真实私聊测试正常。用户已确认“测试正常”。**

## 三、当前技术架构

```text
微信私聊 / 群聊 @大肥鱼
          │
          ▼
本地微信数据库与媒体缓存
          │
          ▼
Python 桥接 bridge.py
  ├─ 消息分类、会话状态、引用解析
  ├─ 文字对话 ── OpenClaw ── DeepSeek API
  ├─ 图片/表情/GIF ── 媒体提取 ── DeepSeek 视觉 API
  └─ 搜索/核实 ── SearXNG + 网页读取 ── 模型归纳
          │
          ▼
微信 Hook 后台发送
          │
          ▼
数据库核验发送结果
```

### 组件职责

- **微信 Hook**：后台发送消息，避免通过模拟鼠标输入回复。
- **Python 桥接**：读取消息、识别指令、维护会话、调用模型并核验发送。
- **OpenClaw**：承载文字对话、人设、会话上下文和已配置的联网工具。
- **DeepSeek API**：当前唯一模型推理来源，包括现有视觉调用。
- **SearXNG**：提供搜索结果；结合网页内容读取形成回答依据。
- **后台任务与守护**：启动和恢复服务，等待微信上线，执行停止标记。
- **BotSwitch.exe**：提供启动、关闭及状态展示。

当前不依赖 Docker Desktop 来提供搜索，使用已有的 WSL 原生 SearXNG 部署。

## 四、当前功能

### 4.1 私聊对话

- 使用 DeepSeek 回复普通文字消息。
- 保留自然分段、口语化回复和大肥鱼人设。
- 按联系人隔离会话，不将不同私聊用户合并为一个上下文。
- 回复状态栏保留模型名称、输出字数、耗时；实际联网时显示“已联网”。
- 每日首次对话发送公告，日期按东京时间动态生成。

人设中的尾巴、白饭等内容按此前要求降低主动提及频率。这是提示词约束，仍可能偶发重复或模板化措辞。

### 4.2 群聊

- 通过明确 @ 机器人进入交互。
- 普通回复保持单段，并使用现有发送者名称解析与原生 @ 机制。
- 支持模型对话、联网搜索、引用内容分析与群聊总结。
- 群聊总结当前读取上限为最近 70 条消息，排除 Bot 自己的消息；文本长度另有保护。
- 群聊按群保存上下文，不能将其理解为每个群成员拥有完全独立的私聊式记忆。

群队列代码保留，但审查发现数据库大锁会串行化部分处理。当前不能承诺慢请求不影响其他会话。

### 4.3 图片、表情包与 GIF

- 现有图片、表情包和 GIF 媒体提取流程保留。
- 图片识别统一调用 DeepSeek 视觉 API，不再回退千问。
- 支持优先处理引用图片，以及已有的发送者附近图片关联规则。
- 相关引用图片查找使用最近 50 条消息，与群总结的 70 条窗口不同。
- 私聊文字后紧随的表情包，在符合原有条件时作为情绪补充；群聊不采用此合并逻辑。
- 保留视觉回复的简洁要求、字数与耗时，以及媒体失败提示。

这里表示调用路径保留，并不代表识图一定正确。真实图片可能受缓存、密钥、格式、模型支持和候选图片定位影响；GIF 的现有实现也不等于完整视频时序理解。

### 4.4 联网与引用分析

- 保留自然联网判断。
- 支持直接说“搜索……”或“核实……”，兼容 `/search`。
- 支持引用文字评论，以及对引用文字执行核实。
- 图片联网搜索继续使用“识别可见特征 → 提取关键词 → 搜索并归纳”的方式，不等于通用反向图片检索。
- 搜索回答以归纳为主，明确要求来源链接时提供链接。
- 搜索后的短追问结合当前会话的搜索主题处理。

搜索可用、搜索结果相关及最终结论正确是三个不同条件；“已联网”标记不代表结果已经百分之百核实。

### 4.5 上下文、夜间与启停

- 保留上下文压缩、重置与会话清理指令。
- 历史会话迁移保留水位、epoch 和既有历史。
- 保留东京时间 00:00–08:00 的原有夜间规则。
- 私聊夜间按离线逻辑处理；群聊夜间不自动响应对应时段消息，上线后的新引用请求仍可进入处理。
- 保留后台自启；微信不自动登录。
- 通过控制台关闭后，可阻止本次开机期间的守护自动拉起。

## 九、隐私与使用边界

- 当前推理使用远程 DeepSeek API，提交的对话和识图图片会发送给该服务。
- 搜索会向搜索服务和相关网站提交必要查询或请求。
- 本机仍保存必要的会话状态、缓存和日志；备份可能包含私有信息。
- API 密钥、配置保护备份、微信数据库、二维码及私人媒体不应提交到 GitHub。
- 当前微信 Bot 没有新增通用电脑控制、任意文件读取或游戏代玩能力。
