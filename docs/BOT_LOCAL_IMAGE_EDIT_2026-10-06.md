# 恢复本地改图

使用当前D:/AI/QwenImage21的Qwen-Image-2.1模型与sd-cli运行器，以用户图片作为图像输入（--reference / -r）。旧ComfyUI编辑服务不启用。

## 使用流程

1. 私聊发送“改一下图片”；群聊发送“@大肥鱼 改一下图片”。
2. 同一发送者在该消息之后5秒内发送图片。
3. Bot收到图片后回复“需要修改什么？请告诉我具体要求。”
4. 在5分钟内发送文字修改要求；群聊这一步可以继续@，也可以直接发文字。
5. Bot确认入队，生成并发送新图片及“本地改图”耗时栏。

没有图片时提示重发请求；要求过长、队列已满、图片解码/生成/发送失败均给出提示。会话按聊天和发送者隔离，忽略Bot自身消息。图片等待窗口用消息时间检查，避免把晚发的图片错误关联。等待修改要求时发送“取消”取消；斜杠指令退出等待并沿用原指令逻辑。夜间消息仍按现有规则处理。

## 实现及验证

- local_edit_flow.py维护短期状态，持久化到local_image_edit_pending。
- bridge.py在普通识图/文字回复前分流改图消息；复用全局DrawingDispatcher串行队列。
- image_generation.py原图编辑分支跳过联网参考及生图专属构图/负面提示，要求保留未指定修改的部分。
- 141项回归检查通过。
- 本机512×512、10步低成本实图测试：蓝色蝴蝶结成功改为红色，整体角色和构图保留；输出7130089df95a4b8a9403feb2936ff88b.png。其他蝴蝶结也变红，轮廓存在小变化，说明模型编辑不是像素级局部替换。
- Bot默认仍为768×768、28步；原图不覆盖。尚未完成用户微信端的实际完整流程验收。
