## 3. 已实现功能

### 对话、群聊与记忆

- 私聊保留自然分段；群聊通过 @ 入口触发，单段回复，并 @ 对应发送者。
- 各会话有独立处理队列；本地模型和绘图的共享算力仍可能造成等待。
- 私聊按联系人隔离上下文；群聊使用群会话上下文。
- 模型切换：切换大肥鱼、切换千问，兼容 /deepseek、/qwen；支持切换后接问题。
- /fast、/think、/compact、/reset、/clear、/help。
- 每日公告使用当天动态日期，当前版本文案 0.4。
- 自然联网及“搜索”“核实”入口，兼容 /search；联网成功按实际资料获取情况显示“已联网”。
- 搜索后的短追问结合前一主题重新检索，避免直接沿用旧回答。
- 自动压缩和明确截断信号的一次重试；合法短回复不再仅凭字数被视为异常。
- 东京时间 00:00–08:00 的私聊按离线规则处理；群聊该时段不触发回复，上线后的新引用请求仍可处理。
- 人设保留蓝鲸身份和自然口语，降低尾巴、白饭等设定的主动出现频率。

### 识图与引用

- Qwen 和 DeepSeek 均有视觉调用路径，支持图片、表情包及 GIF 的现有处理流程。
- 优先处理引用图片；相关引用查找使用最近 50 条消息。
- 识图命令关联同一发送者附近的图片；群聊支持指定识图请求后等待媒体。
- 私聊中，紧随文字且符合条件的表情包可作为情绪补充；群聊不加入此合并逻辑。
- 引用文字可用于评论；核实类请求进入联网检索。
- 图片搜索使用“视觉描述 → 关键词检索 → 归纳”的路径，不应视为通用反向图片检索。
- 输出带字数、耗时；失败有提示。具体图片解码和模型准确率仍需真实消息验证。
- 群聊总结当前配置为最近 70 条消息，排除 Bot 自身；与引用图片的 50 条检索窗口不同。

### 绘图与改图

- “画……”及 /draw 进入绘图队列；普通主题直接画，特定人物按现有分类逻辑检索参考。
- 当前默认 768×768、28 步；生成 CFG 3，改图 CFG 6。
- 生图不再注入固定 Bot 自设外观；用户要求优先于参考图的服装、姿势及背景。
- 已取消全局压暗、去饱和和强制灰背景约束，保留避免多余文字、Logo 等提示。
- 新本地改图流程当前启用：发送“改一下图片” → 同一发送者 5 秒内发图 → Bot 询问要求 → 5 分钟内提交修改要求。
- 旧 ComfyUI 编辑路径停用。新流程复用绘图队列，保留原图。
- 本地绘图使用共享 GPU，期间会暂停并恢复本地文字后端；因此文字服务并非始终能同时推理。

## 4. 当前限制与需要复验的部分

1. 生图时间：专项记录中一次 768×768、28 步生成约 239 秒，不包含后端恢复及发送；不是当前所有任务的平均值。
2. 新本地改图已有低成本实图测试，但专项记录未完成微信端完整验收。可能连带修改非目标区域。
3. 色彩、人物参考和指令遵循已做修正，但少量成功图片不能证明所有场景稳定。
4. 微信媒体缓存或 AES 密钥不可用会导致真实图片解码失败；代码测试通过不能替代媒体链路实测。
5. 当前端口检查不能证明最新搜索质量、识图准确率或长时间无故障运行。
6. 人设最终调整仍需持续实际聊天观察，千问可能出现重复措辞或泛泛追问。
7. 旧总览包含默认模型、DeepSeek 识图、修图停用等过时段落，应参考本文件与较新的专项记录。
8. 本次未执行测试集，也未确认 GitHub 与本地代码完全同步。
