# 生图色调与参考图优先级修正

## 已确认的问题

最新用户任务03531857df994d6ba637ed9347d0f990要求“原神芙宁娜的泳装全身图”。联网参考为米游社原服装坐姿插画，含鲜蓝衣服和青蓝背景。输出基本复制原服装、坐姿和家具，且服装变为黑灰。日志证明实际使用了全局压暗、降饱和及灰背景约束，运行器CFG固定为6。

## 最终修改

- 取消全局曝光、饱和度、强制灰背景及“鲜亮”增强提示。取消对应高调光、粉彩等负面约束。只保留用户明确提出的颜色描述。
- 联网参考只用于识别角色脸部、头发及身份特征。用户要求优先；明确要求换服装、姿势、构图时必须替换参考对应部分，不继承其家具和背景。
- 生图引导强度改为3，768×768、28步保留。改图使用独立参数6，保留之前验证过的编辑路径。
- 运行器支持--cfg-scale，验证范围1至10；Bot拒绝非有限及越界值。

## 实图测试与限制

1. 保留原参考、原种子55777367、768×768/28步和CFG6，改用“鲜亮/颜色忠实”提示：color-fidelity-20261006.png。灰黑问题消失，但过饱和；没有采用这一中间方案。
2. 去掉全局色调提示，加入用户优先规则，512×512/10步、CFG6：reference-priority-20261006.png。泳装和站姿实现，但严重过曝；没有采用这一参数组合。
3. 最终规则，768×768/28步、CFG3：reference-priority-cfg3-20261006.png。已查看：浅蓝泳装、站立全身图；浅色和皮肤细节可见，未被压成黑灰或完全冲白。运行器生成239.34秒，不包含后端恢复及微信发送。

以上测试并非对所有提示、角色及颜色的保证；第二与第三项除CFG外还改变了尺寸和步数，不能单独证明CFG是唯一原因。最终采用经实图验证的组合。
