# Bot 本地生图接入

## 使用

私聊：

```text
画一张海边的蓝色鲸鱼娘
/draw 一只躺在沙发上的橘猫，日系插画
```

群聊：

```text
@大肥鱼 画一张蓝色鲸鱼娘抱着鲸鱼玩偶
@大肥鱼 /draw 日落时的东京街道
```

“帮我生成一张……”“生图：……”也可以触发。
Bot 先发送排队确认，成功后发送图片和“本地生图、分辨率、耗时”提示。
群聊确认及完成提示 @ 实际请求者。缺少描述、队列满或生成失败会给出提示。
/help 和每日公告增加生图用法。

## 实现

- bridge.py：指令解析、私聊和群聊派发、图片发送及数据库确认。
- image_generation.py：全局单绘图线程、最多8个等待任务、调用本地生成脚本、验证 PNG。
- D:\AI\QwenImage21：已部署的模型、Vulkan 运行程序和 generate.py。
- 默认512×512、20步、单任务推理超时360秒。
- 使用 Hook 后台发送图片，继承现有00:00–08:00静默规则。
- 生成与识别使用独立入口，现有修图仍停用。

## GPU 共用

绘图等待千问当前推理完成，暂停项目文字后端，再运行图像模型。
图像进程退出并恢复文字后端后，排队的本地千问请求继续处理。
文本、视觉及会话压缩共用重入锁，防止千问推理过程中被绘图卸载。
数据库锁仅用于确认和发送，不在整个绘图期间持有，避免模型锁与数据库锁互相等待。
队列在内存中；进程异常退出或被强制停止后，未完成绘图请求需要重发。

## 配置

在本机 config.json 中新增以下选项，未启用的其他部署默认不开放生图：

```json
{
  "image_generation_enabled": true,
  "image_generation_root": "D:/AI/QwenImage21",
  "image_generation_width": 512,
  "image_generation_height": 512,
  "image_generation_steps": 20,
  "image_generation_timeout_seconds": 360,
  "image_generation_max_pending": 8
}
```

部署至其他电脑时，需要安装模型组件并修改生成脚本中的 Bot 目录路径。
实际生图使用本地模型，与聊天选择 DeepSeek 或 Qwen 无关。
