# 绘图联网参考

## 使用

沿用“画一张……”和 `/draw`，群聊仍需 @机器人。生图先联网检索参考图，再由本地 Qwen-Image 绘制；不是把搜索结果当作生成图片直接发送。

自画像请求转换成“DeepSeek 鲸鱼娘 深蓝 长发 女仆 立绘”检索。其他主题使用用户的画面描述，最多取180字符作查询。使用本机 SearXNG 的 images JSON 接口：https://docs.searxng.org/dev/search_api ，图片字段说明：https://docs.searxng.org/dev/result_types/main/image.html 。没有新增付费搜索 API。

## 流程

1. 最多检查12条图片结果，下载至多4张候选；下载体积、分辨率和耗时有上限，拒绝本地地址及过长截图。
2. 千问视觉通过带编号的拼图选择相关、主体清晰的参考。拒绝结果或无匹配时按文字绘制，不把第一张结果强行当参考。
3. 合格参考图与来源记录保存在 D:/AI/QwenImage21/references/web，按查询缓存24小时。角色换姿势或场景时可复用相同外观参考。
4. 生图运行器通过 `--reference` 将实际文件交给模型，底层启用视觉投影并传入 `-r`。人设描述强调深海军蓝头发；未明确要求改发色的自画像额外排除青绿头发。
5. 状态栏区分“已联网参考”“参考图缓存”“未找到合适参考，按文字绘制”。耗时包含检索、筛选、生图和文字模型恢复。来源不默认发到群或私聊。

可以在 config.json 设置 `image_generation_search_enabled: false` 关闭此流程；默认开启。若 SearXNG 或视觉服务失败，会标注没有合适参考并按文字生成，不冒充检索成功。

## 动物绘图指令漏判修复

17:24用户发送“画一只黄色小猫”，日志记录kind=prompt，进入普通文字模型。原因是绘图解析仅支持张/个/幅，漏了动物量词只/条/匹/头。补齐这些量词后，该句解析为draw，提示词为“黄色小猫”。私聊分类及群聊@提取后的绘图入口共用同一解析函数；普通聊天“我画了一只猫”等仍不触发绘图。129项检查通过，未自动重发或重新执行用户的旧请求。
